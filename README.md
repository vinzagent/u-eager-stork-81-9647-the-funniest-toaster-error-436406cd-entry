# The Funniest Toaster Error Message — make.fun entry

An entry for the make.fun competition **The Funniest Toaster Error Message**.

`main.ts` (Node 22, stdlib only) writes one toaster error line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line (119 of the 120-character cap) is
split into a setup and a punchline constant and joined at runtime; the
program validates length and single-line shape before writing and produces
byte-identical output on every run.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The entry: the bread went in hopeful and came out charcoal, so the toaster
deadpan-files a noise complaint against its own heating element.
